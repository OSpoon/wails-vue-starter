# AGENTS.md

## Quick start

```sh
wails3 dev          # dev with hot-reload (Go + Vite)
wails3 build        # production build → bin/
```

## Project layout

```
main.go                    # Go entrypoint (package main, not cmd/)
greetservice.go            # Example service bound to frontend
frontend/                  # Vue 3 + TS + Vite 8 app
  src/main.ts              # Vue entrypoint
  src/App.vue
  src/components/          # App components
  src/components/ui/       # shadcn-vue UI components (Button, etc.)
  src/lib/utils.ts         # cn() utility (clsx + tailwind-merge)
  src/style.css            # Tailwind v4 + shadcn-vue CSS variables
  bindings/                # Auto-generated TS bindings (do not edit)
  dist/                    # Built frontend (embedded via //go:embed)
  components.json          # shadcn-vue config (aliases, style, icon lib)
build/
  config.yml               # Wails3 build config (version, metadata, dev mode)
  Taskfile.yml             # Common tasks (build frontend, generate bindings, etc.)
  darwin/Taskfile.yml      # macOS build tasks
```

## Package manager

pnpm (default). Bun, npm, and yarn also supported via `PACKAGE_MANAGER` env var.

## Module placeholder

`go.mod` declares `module github.com/OSpoon/wails-vue-starter` — change this to your actual module path.

## Key frontend commands (run from `frontend/`)

| Command | What it does |
|---------|-------------|
| `pnpm dev` | Vite dev server on port 9245 (strict) |
| `pnpm build` | `vue-tsc --build` + `vite build` (via npm-run-all2) |
| `pnpm type-check` | `vue-tsc --build` |
| `pnpm lint` | oxlint + eslint (both --fix) |
| `pnpm format` | Prettier (no semi, single quotes, printWidth 100) |

## Lint & format conventions

- **oxlint** is the primary linter, **ESLint** is secondary (both run on `pnpm lint`)
- Both run with `--fix` by default
- Pre-commit hook: `cd frontend && pnpm lint-staged` — runs eslint --fix + prettier --write on staged `.vue`, `.ts`, `.mts`, `.tsx` files
- Prettier: `semi: false`, `singleQuote: true`, `printWidth: 100`

## Type checking

`vue-tsc --build` (not `tsc`). Config via `tsconfig.json` → references `tsconfig.app.json` + `tsconfig.node.json`.

## Vite dev

- Port: `WAILS_VITE_PORT` env var or `9245`
- `strictPort: true` — fails if port is taken
- Path alias: `@/` → `./src/`

## shadcn-vue UI components

- Components live in `src/components/ui/` — added via `npx shadcn-vue@latest add <component>`
- Config: `components.json` (aliases, style "vega", icon lib "lucide")
- Uses Tailwind CSS v4 + reka-ui primitives
- Import utility: `import { cn } from '@/lib/utils'` for conditional class merging
- ESLint rule `vue/multi-word-component-names` is off for `src/components/ui/`

## Bindings (Go ↔ TS)

Auto-generated by `wails3 generate bindings`. Output lands in `frontend/bindings/`. Edit Go service structs, then regenerate — never edit bindings by hand.

## Build system

Taskfile.yml (go-task), not GNU Make. Use `wails3 task <name>` to invoke tasks.

## Wails3 dev mode flow (`build/config.yml` `dev_mode.executes`)

1. `wails3 build DEV=true` (blocking — compiles Go + frontend)
2. `wails3 task common:dev:frontend` (background — starts Vite HMR)
3. `wails3 task run` (primary — launches the native binary)

## Server mode (no GUI)

```sh
wails3 task build:server   # builds with -tags server
wails3 task run:server     # builds + runs
wails3 task build:docker   # Docker image for server mode
wails3 task run:docker     # runs container on port 8080
```

## macOS specifics

- Build universal binaries: `wails3 task darwin:build:universal`
- Signing config lives at the top of `build/darwin/Taskfile.yml`
- Ad-hoc signing happens automatically during `run` and `package`

## Git hooks

simple-git-hooks (configured in `frontend/package.json`). Install with `wails3 task common:install:git-hooks`.

## Generated / ignored artifacts

- `bin/` — compiled binaries
- `frontend/dist/` — built frontend (embedded by Go `//go:embed`)
- `frontend/node_modules/`
- `.task/` — Taskfile cache
