# wails-vue-starter

A Wails3 + Vue 3 + TypeScript starter template with shadcn-vue components.

## Template foundation

This starter includes a small desktop-app foundation on top of the default Wails app:

- `AppService`: application metadata, runtime environment, browser opening, clipboard helpers, and a `app:ready` event.
- `PreferenceService`: JSON-backed user preferences stored under the OS user config directory.
- `MarshalError`: stable `{ code, message, details }` service error payloads for the frontend.
- Lifecycle-aware service registration with `ServiceStartup` and `ServiceShutdown`.
- Typed Wails events generated from Go with `application.RegisterEvent`.
- Frontend composables for app info, preferences, automatic event cleanup, async error handling, and window state persistence.
- Frontend native facades for browser, clipboard, dialogs, and window runtime APIs.

Generated TypeScript bindings live in `frontend/bindings/` and are intentionally ignored. They are regenerated by the Wails build tasks. Run this directly when changing Go services:

```sh
wails3 generate bindings -clean=true -ts
```

## Development

```sh
wails3 dev
```

## Build

```sh
wails3 build
```

Production binaries are written to `bin/`.

## Release

Versioning is driven by `bumpp` from `frontend/package.json`. The bumpp config also updates the
Wails metadata in `appconfig.go` and `build/config.yml`.

```sh
cd frontend
pnpm release
```

The release command creates a `chore(release): vX.Y.Z` commit, creates a `vX.Y.Z` tag, and pushes
both. Pushing the tag triggers `.github/workflows/release.yml`.

The release workflow builds updater artifacts on GitHub-hosted runners:

- `wails-vue-starter-darwin-arm64.zip`
- `wails-vue-starter-darwin-amd64.zip`
- `wails-vue-starter-linux-amd64.tar.gz`
- `wails-vue-starter-windows-amd64.zip`
- `SHA256SUMS`

The artifact names include `GOOS` and `GOARCH` so the Wails3 GitHub updater provider can match the
right download. `SHA256SUMS` is published alongside the artifacts for updater checksum verification.

The same release also publishes user-facing installers/packages:

- `wails-vue-starter-darwin-arm64.dmg`
- `wails-vue-starter-darwin-amd64.dmg`
- `wails-vue-starter-windows-amd64-installer.exe`
- Linux `.AppImage`, `.deb`, and `.rpm` packages
